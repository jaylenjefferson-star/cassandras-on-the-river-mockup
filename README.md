# Cassandra's on the River — Website Mockup

A premium single-page website mockup for **Cassandra's on the River**, an authentic
Cajun & Creole seafood restaurant in Shreveport, LA. Built to demonstrate a modern,
high-quality restaurant UX for client review.

## Live Demo

Once GitHub Pages is enabled, the site is available at:
`https://jaylenjefferson-star.github.io/cassandras-on-the-river-mockup/`

## What's included

- **Sticky navigation** with an always-visible "Reserve a Table" call to action
- **Full-bleed hero** with animated imagery and trust stats
- **Scrolling flavor marquee** of signature dishes
- **About** section with overlapping imagery and key selling points
- **Happy Hour** bar menu (Tue–Fri, 3–6 PM)
- **Interactive tabbed menu** (Starters / Mains / Seafood Boils / Sweets)
- **Hover-reveal photo gallery**
- **Careers** recruiting call to action
- **Reservation request form** (demo) with click-to-call contact details
- Fully **responsive** with a mobile menu and reduced-motion accessibility support

## Tech

Plain HTML, CSS, and vanilla JavaScript — no build step required.

- `index.html` — page structure
- `styles.css` — design system and layout
- `script.js` — navigation, scroll reveal, menu tabs, form handling

## Notes

This is a design mockup. Menu items and prices are illustrative placeholders, and
images are stock photography standing in for the restaurant's real photos. Business
details (name, location, phone, happy hour) reflect the real establishment.
